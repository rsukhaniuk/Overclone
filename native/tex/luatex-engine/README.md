# Source-built browser LuaTeX

LuaTeX **1.13.0 / svn 7410**, Lua **5.3.6**, from approved TeX Live 2021
source `22d3aa7aded98382a59b1f3dc0e7142a810bdeca`; Emscripten **6.0.13**.
`build.sh` uses upstream make/CWEB plus approved native generators. Missing
`otangle` is built through TANGLE/Web2C. Authored source overlays are checked;
`luatex-core.c` is regenerated by the upstream Lua self-generator body, never
edited. Its unused stripped-Lua sidecar uses identity compaction. No vendor
source, generated C, engine binary, font or format is stored in this subtree.

## ABI 2

See `engine.h`. Instantiate supplied WASM bytes through `instantiateWasm`, with
**one fresh module per attempt**. Configure exact UTF-8 root and opaque ASCII
revision context; seed verified runtime/project files. No normalization or source
rewriting. Root ASCII characters are limited to letters/digits/`._-/ `, rejecting
TeX syntax. Malformed UTF-8, traversal and unsafe relative paths reject.

The genuine `lualatex.ini` generates `lualatex.fmt`; format generation must use
trusted runtime only, not project overrides. Compile with `--jobname=result`:
root runs its existing separate BibTeX on `result.aux`, returning `result.bbl`.
Ten indexed outputs remain available. `declare_output` adds explicit generated
AUX/BBL/BLG/TOC/LOF/LOT/OUT names and precreates parents; only declared names may
be carried or retrieved by the named APIs. Actual nested `\include` AUX carry is
tested. No filesystem listing/export API is provided by the C ABI.

Input limits: 4,608 files / 96 MiB aggregate; runtime files 32 MiB, project/carry
files 8 MiB. Selected outputs cap at 128 including defaults. WASM memory is 512 MiB.
At compile entry the SDK6 guard automatically seals the supplied `/work` VFS:
**16 MiB logical high-water growth and a shared 16 MiB cumulative backing-allocation
plus allocating-copy budget**, 8 MiB generated files (INITEX 32 MiB), 128 lifetime
new-node attempts and 256 KiB log/terminal bytes. Shrink/delete never refund work.
Raw ABI copy ceilings remain 32 MiB/file and 64 MiB selected aggregate; the active
guard is stricter. `oc_luatex_budget_json` reports counters, latch and truncation.
Negative statuses: -1 invalid input, -2 lifecycle, -3 VFS, -4 quota, -5 no expected
output. Positive statuses are engine failures. Failure or rejected reuse revokes
PDF/format/state access; logs remain available. Context correlation remains the
parent's responsibility.

## Build and checks

`bash native/tex/luatex-engine/build.sh` writes only private `/control` outputs,
uses the private SDK cache copy, frozen cache/dead proxies, jobs <= 2 and bounded
commands. No acquisition. `RELINK_ONLY=1 bash .../link.sh` compiles only the owned
wrapper and relinks existing dependency objects; no whole build is required.
Test entry points: `test-engine.cjs format`, `test-engine.cjs latex`,
`test-abi.cjs`, `test-cancellation.cjs`, and `inspect-fixture.py PDF [--include]`.
The PDF inspection is a narrow compressed text/ToUnicode assertion, not a renderer.
Exact commands, hashes, runtime manifests, failures and results are in the private
frozen handoff receipt; `lineage.json` records source/toolchain identities.

FFI/socket modules are not registered or linked. Process APIs/C loaders are
revoked; shell escape is disabled. Real hostile Lua/TeX requests and private-VFS
reads/writes are tested, not merely ENOSYS stubs. Minimal pre-js/EM_JS is required
because MEMFS allocations live outside WASM. Forty-one exact SDK6 function shapes
are validated with WebCrypto and shared aliases are patched in place. Vector
staging, ownership views, write/truncate/seek, copies, node creation and logs are
preflighted before allocation; mmap, new links/devices/mounts are refused. Runtime/
config are immutable; outside reads return ENOENT without host lookup. Quota failures
latch even if Lua catches them, revoking PDF/state through both getter APIs. The
format writer uses one charged 14 MiB backing reservation to avoid unbounded
geometric reallocations; bytes still come solely from the genuine engine.
**The parent still bounds snapshots/state/transport, denies network authority and
physically terminates workers.** No complete-sandbox or final browser acceptance
claim follows from the actual native/Node-worker checks.
Normal fontspec family-name and explicit-TTF Ukrainian documents pass with genuine
provided packages/fonts. LuaHBTeX/HarfBuzz shaping, comprehensive package coverage,
SyncTeX transport, final PWA/browser acceptance and redistribution clearance remain
outside this candidate. Licensing remains upstream; no distribution is authorized.
